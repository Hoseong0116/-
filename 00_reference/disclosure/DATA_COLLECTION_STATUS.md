## 최우선 수집 목록

### P0 — S0 재현과 최종 비교를 막는 자료

1. UD 12대 실제 운행자료: 차량×호출 또는 차량×일 단위 장애인/일반 운행, 거리, 매출, 지원금.
2. 월 100건 운영지침·협약: 산정단위, 초기화, 달성 후 상태전이와 배차규칙.
3. 2025 장애인콜택시 호출·배차·대기 로그: 호출시각, 배차시각, 차량도착·승차시각, 출발·도착 지역, 취소·미배차.
4. UD 보조금·인센티브 산식 및 정산지침.

### P1 — 차량·충전·기회비용 계산에 필요한 자료

1. 기존 fleet 자산대장: 차종×연식×연료×특장 여부와 차량수.
2. UD BMS/SOC·충전 로그: 시작·종료 SOC, kWh, 시간, 급·완속, 충전소.
3. 서울 PV5 호환 충전소 실제 레코드.
4. 일반택시 시간×지역 매출·공차·승차거리 자료.
5. 서울 자동차용 LPG 최근 12개월 가격 원자료.

### P2 — 정밀 비용 산정용 자료

1. 민간·완속 충전 사업자별/시간대별 전기요금.
2. 최신 보험·정비·특장 유지비와 기사 인건비·관리비.
3. PV5 WAV 보조금 실액, 순구매가, 보증 및 미확보 제원.
