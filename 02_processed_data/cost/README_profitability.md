# UD 12대 S0·S1 수익성 입력자료

2026-09-17 공개자료 조회, 2026-09-18 정리. CSV는 Excel 한글 호환을 위한 UTF-8 BOM이다. 기존 충전소 파일, 시간대 영업자료, 차량원가는 변경하지 않았다.

## 비교 범위

S0: 차량 12대 각각 월 장애인 운행 100건 우선 후 일반영업 가능. S1: 같은 차량·수요에서 의무건수 없이 수요기반 동적운영. 기존 장애인콜택시 fleet는 두 시나리오에 유지한다.

우선 지표는 UD 운영주체의 월 변동비 차감 수입(공헌이익)과 S1−S0 차이이다. 이는 보험·감가상각·공통 인건비까지 뺀 순이익이 아니다. 동일한 고정비는 증분 비교에서 상쇄되지만 근무시간·총운행거리 차이에서 생기는 추가비용은 반영한다. 전체 공공운영기관 비용 비교는 범위가 다르다.

공헌이익 = 장애인 승객운임 중 운영사 귀속액 + 운영사 귀속 보조금 + 일반영업 수입 − 충전비 − 호출/결제 수수료 − 거리비례 정비비 − 추가근무비 − 미보전 기타비용.

보조금이 운임 차액 보전이라면 보전 후 총액과 승객운임을 중복 합산하지 않는다. S1의 보조금 지급방식은 관측 사실이 아니라 연구 정책 가정으로 별도 정해야 한다. 비교는 동일 기간·근무시간·수요·요금 기준과 장애인 서비스 수준을 함께 제시한다. 수입이 늘어도 장애인 서비스가 악화되는지 반드시 같이 본다.

## 확보 데이터와 제한

- fuel_price.csv: 서울 LPG·경유 2026-09-16 일평균(VAT 포함). 월/연 평균 아님. 두 PV5 시나리오 자체에는 불필요하며 기존 내연기관 운행량 변화의 비용을 포함할 때 사용한다.
- profitability_parameters.csv: 서울 중형택시 현행요금, 장애인 승객요금, PV5 공인전비, 연구규칙. 2023년 시행 택시요금은 2026년 갱신 공식 페이지에서 현행 확인했으므로 오래된 운행통계와 구분한다.
- electricity_price_by_operator.csv: 무공해차 통합누리집 회원 공시요금 101사업자 × 5출력구간. 빈값은 공시없음이지 무료가 아니다. 갱신일은 시행일이 아니다. 로밍·비회원·법인계약 요금은 이 표와 다를 수 있다. 서울시 소유 충전소라는 이유만으로 모든 충전기에 특정 단가를 확정 적용하지 않는다.
- operating_cost.csv: 필요한 변동비 항목과 자료요청 상태. 확인되지 않은 단가를 추정하여 넣지 않았다.
- taxi_revenue_hourly.csv: 기존 48행 틀 유지. 최신 관측 매출·공차값은 미확보. 시간당 매출은 운임합계/영업가능 차량시간으로 분모 정의를 통일한다. 공차거리율과 공차시간율은 별개다.
- profitability_missing_requests.csv: 사용자가 직접 신청해야 하는 3종 자료의 대상·기간·필드.
- profitability_sources.csv: 출처 URL과 채택상태.

충전비는 가능하면 세션별 과금 kWh와 적용단가로 산출한다. 공인전비 4.4km/kWh를 실측전비로 표시하지 않는다. 전비 인증의 에너지 측정경계와 충전손실을 확인하지 않은 상태에서 임의 손실률을 중복 적용하지 않는다.

## 원자료 보관

`01_raw_data/profitability/2026-09-17`에 공식 HTML 원본, 텍스트 추출본, 다운로드 URL·해시를 보관했다. S04 HTML은 본문을 얻지 못한 보안 응답이다. 대신 실제 브라우저의 표시된 회원요금 표를 CSV로 전사하고 101행 전체를 해시로 대조했다. 공식 배포 CSV 또는 실제 거래데이터라고 부르지 않는다. S08·S09는 이용경로일 뿐 영업원시자료가 아니다.

S10 논문(2025년)의 2023년 관측값은 사용자 승인 전 미채택이다. 공개자료로 확보하지 못한 값은 빈칸으로 유지한다. 서로 다른 시점의 자료를 같은 관측기간으로 취급하지 않는다. 최신 가격기준의 반사실 시뮬레이션이라면 수요연도(예: 2025)와 가격기준일을 별도로 보고한다.
